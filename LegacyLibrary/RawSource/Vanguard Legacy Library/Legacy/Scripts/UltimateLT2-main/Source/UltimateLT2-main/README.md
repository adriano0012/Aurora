# Ultimate Lumber Tycoon 2 Script

The ultimate all-in-one Lumber Tycoon 2 script, combining the best features from **5 popular LT2 scripts** into a single, polished package with a modern GUI.

> **NO KEY REQUIRED** - 100% Free, always.

## Features

### 🏃 Movement
- **Fly** - Smooth flight with WASD + Space/Shift controls
- **Noclip** - Walk through walls and objects
- **Infinite Jump** - Jump infinitely in mid-air
- **Water Walk** - Walk on water surfaces
- **Speed Hack** - Normal (16) / Fast (50) / Sonic (100)
- **Jump Power** - Normal (50) / High (100) / Moon (200)

### 🪵 Wood & Items
- **Bring ALL Wood** - Teleport all wood in the server to your base
- **Bring Specific Wood** - Choose from 19 wood types (Elm, Phantom, Gold, etc.)
- **Bring Items** - Bring all your dropped items back to base

### 💰 Economy
- **Auto Sell Wood Loop** - Continuously sell wood for money
- **Dupe Inventory** - Duplicate your inventory (requires rejoin)
- **Dupe Axes** - Duplicate axes in your backpack

### 🚀 Teleports
- **17 Map Locations** - One-click teleport to any location
- **Player Teleport** - Teleport to any player in the server

### ⚙️ Visuals & Misc
- **No Fog** - Remove all fog for full map visibility
- **Player ESP** - See player names through walls
- **God Mode** - Become invincible

## How to Execute

### Step 1: Get an Executor

You need a Roblox script executor. Some popular options:
- **Delta** (Android)
- **Fluxus** (PC/Mobile)
- **Arceus X** (Android)
- **Synapse X** (PC)
- **KRNL** (PC)

### Step 2: Copy the Loader Script

Copy and paste this **one-line loader** into your executor:

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/KillerKing93/UltimateLT2/main/ultimate_lt2.lua'))()
```

### Step 3: Execute

1. Join **Lumber Tycoon 2** on Roblox
2. Open your executor
3. Paste the loader script
4. Click **Execute/Run**
5. The GUI will appear!
